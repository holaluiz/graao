# Ability Draft (design for Phase 6 — TODO)

Four simultaneous rounds: Basic, Basic, Basic, Ultimate. No duplicate ownership: when both players pick the same
ability, the player with round priority (alternating per round) keeps it and the other immediately repicks.
Target 30–60 s in 1v1. Pool: 8–10 basics, 3–4 ultimates. The server owns picks and replicates the loadout.
